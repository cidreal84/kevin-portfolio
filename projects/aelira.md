# Aelira

A local-first AI companion for macOS.

Aelira is an AI companion application built with Tauri 2, React, and Ollama. It combines local AI conversations with a VRM-based avatar and a desktop pet experience.

# Features

* Local AI chat: Conversations powered by Ollama.
* Vision: Image understanding using a separate vision model.
* Streaming responses: Stop and retry generation.
* Chat management: Persistent chats, temporary chats, and chat exports.
* Memory: Locally stored, user-approved memories.
* Voice: Voice input and text-to-speech support.
* VRM avatar: Expressions, mood animations, and idle behaviour.
* Desktop pet: A transparent companion window with interactive behaviour.

# Technology

* Tauri 2
* React
* Vite
* Ollama
* VRM / VRMA

# Project Direction

Aelira is designed as a local-first desktop AI experience. Future plans include exploring an iPad and iPhone version.
